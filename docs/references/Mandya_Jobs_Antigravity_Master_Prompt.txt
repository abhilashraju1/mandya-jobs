PRODUCT SCOPE AND RULES
PWA only; works in mobile/tablet/desktop browsers. Initial Mandya city, district expansion through configurable locations. Candidate applications are free. Employers post jobs for hotels/restaurants, hospitals/clinics, schools/colleges, showrooms, shops, auditor/CA offices, lawyers/legal offices, logistics, driving, manufacturing, agriculture/dairy, IT, office/admin, technicians, security, housekeeping and more. Categories and skill synonyms are admin-managed. No unverified jobs publicly visible. Job match score is a recommendation, not an automatic application gate. Support walk-in hiring, fresher jobs, part-time, full-time, internships, temporary/contract, on-site/hybrid/remote when appropriate. Preserve accurate job status and expiry.

Monorepo pnpm + Turborepo. apps/web: Next.js App Router, React, TypeScript, Tailwind CSS, shadcn/ui, Lucide icons, i18n and accessible forms. apps/api: NestJS modular monolith, REST /api/v1, OpenAPI, schema validation, PostgreSQL + Prisma, RBAC and organization scoping. packages/ui, types, validation, config, i18n. Private R2-compatible object storage; Redis/BullMQ for background notifications and expiration where needed; provider abstractions for OTP, email and WhatsApp/SMS. Docker Compose local dependencies; GitHub Actions; structured logs, error tracking and backups. Verify latest compatible stable versions using official docs; pin dependencies. Deploy Next.js to compatible web hosting and NestJS to a compatible Node runtime. No secrets committed. Do not deploy or incur costs without approval.

Resume manager for PDF/DOCX and optional TXT/pasted text: validation, malware scan/quarantine, safe parsing, editable extracted fields and skills, versioning, download/delete and profile-generated resume. EMPLOYER MODULES
Organization registration, legal/display name, category, branches, authorized contacts, verification evidence if needed, logo, description, team members and roles. Separate organization verification and vacancy approval. Job creation wizard: draft/autosave, job title, sector, job type, work mode, locality, full address or privacy-safe display, min/max salary and pay period, negotiable flag, experience, education, required/preferred skills, vacancy count, schedule, benefits, description, deadline, walk-in toggle/dates/times/venue, application method and contact preference. Live job preview. Draft, submit, review, changes requested, approve, publish, reject, close, expire, archive, renew and duplicate. Material changes to published jobs require versioned reapproval, with previous approved version retained until decision. Dashboard and applicant pipeline, authorized candidate/resume access, shortlist/reject with reason, interview scheduling and updates, hiring outcome, reports and activity log. No cross-organization leakage.

ADMIN MODULES
Employer verification, pending/rejected/approved/flagged vacancy queues, job details and version comparisons, reasoned approve/reject/request changes, moderator notes, immutable audit history, candidate/organization administration, complaints and escalations, taxonomy CRUD (sectors, qualifications, skills, Kannada/English aliases, Mandya locations), CMS/FAQ/announcements, notification templates, operational analytics and role administration. Fraud heuristics flag registration fees, invalid contacts, suspicious claims, duplicate ads, misleading salary and unsafe content; human review determines outcome. Clear policy against charging candidates recruitment fees. Never expose demo reset or admin review publicly.

JOB AND APPLICATION STATE MACHINES
Jobs: draft -> submitted -> under_review -> changes_requested/approved/rejected -> published -> closed/expired/archived; define valid transitions, permissions and audit events. Applications: submitted -> viewed/under_review -> shortlisted -> interview_scheduled -> interviewed -> offered -> hired, with rejection or withdrawal as permitted branches. Prevent duplicate active applications, race conditions and unauthorized transitions; retain history and resume/job snapshots.

MATCHING
Transparent deterministic scoring version 1: required skills 30, qualification 25, experience 20, location 15, salary/preferences 10, configurable and testable. Evaluate mandatory eligibility separately; missing data must not produce misleading confidence. Normalize skill aliases across Kannada/English and common transliterations. Explain matched and missing criteria; score is advisory and never auto-rejects candidates. Use fixtures for illustrative 92%, 78%, 34% results but compute them, never hardcode. AI/embeddings/pgvector only later behind feature flag after privacy, bias and quality evaluation.
